# 心情笔记本

一个轻量的心情记录 Web 小程序，单文件、无后端、数据留在本地。

## 功能

**记录**
- 选择心情 emoji（😊 😌 🥰 😔 😤 😢 🤔 😴）
- 混合式日记块：自由组合 📝 文字、🎙️ 语音、📹 视频，一篇日记可包含多种媒体
- 语音录制自动转文字（需 Chrome / Edge，依赖 Web Speech API）
- 添加自定义标签，自动记录当前天气与时间段

**阅读**
- 每篇日记以「每日预言家报」风格呈现：维多利亚式金色边框、羊皮纸底纹、经典衬线排版
- 视频以复古黑白胶片滤镜展示，语音附带转录全文

**浏览**
- 标签云：按标签筛选所有记录
- 笔记列表：支持按标签过滤，点击查看详情或删除

**AI 心情分析**（需要 DeepSeek API Key）
- 一键分析最近记录，给出共情式解读、可能的情绪成因与小建议
- 分析结果可保存为「回忆」，随时回顾
- 支持设置定期提醒（每天 / 每三天 / 每周）

**外观**
- 四种封面配色：暖棕 / 墨蓝 / 樱粉 / 苔绿
- 动态背景随天气变化（晴天粒子、阴天云朵等）

## 使用

### 纯文字模式

直接用浏览器打开 `index.html`，无需安装。

### 语音 / 视频模式

媒体录制需要 `https` 或 `localhost` 环境，本地运行：

```bash
cd mood-notebook
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

如需 AI 分析功能，点击右上角 ⚙️，填入 [DeepSeek API Key](https://platform.deepseek.com)。

**数据备份**
- **导出**：点击顶栏「↓ 导出」，将所有笔记和回忆下载为 JSON 文件
- **导入**：点击「↑ 导入」，上传之前导出的 JSON 文件即可恢复（会覆盖当前数据）

## 数据说明

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 文字笔记、标签、回忆 | `localStorage` | 清除浏览器缓存会丢失，建议定期导出 |
| 语音、视频 Blob | `IndexedDB` | 同一设备浏览器内持久保存 |

> 所有数据留在本地，不上传任何服务器。

## 技术栈

纯 HTML + CSS + JavaScript，零依赖，单文件交付。

| 特性 | 实现方式 |
|------|---------|
| 媒体录制 | MediaRecorder API |
| 语音转文字 | Web Speech API（Chrome / Edge） |
| 媒体存储 | IndexedDB |
| 报纸排版 | 纯 CSS（多层 box-shadow 边框、repeating-linear-gradient 羊皮纸纹） |
