# 心情笔记本

一个轻量的心情记录 Web 小程序，单文件、无后端、数据留在本地。

## 功能

**记录**
- 选择心情 emoji（😊 😌 🥰 😔 😤 😢 🤔 😴）
- 写下文字，添加自定义标签
- 自动记录当前天气与时间段

**浏览**
- 标签云：按标签筛选所有记录
- 笔记列表：支持按标签过滤，点击查看详情或删除

**AI 心情分析**（需要 DeepSeek API Key）
- 一键分析最近记录，给出共情式解读、可能的情绪成因与小建议
- 分析结果可保存为「回忆」，随时回顾
- 支持设置定期提醒（每天 / 每三天 / 每周）

**外观**
- 四种封面配色：暖棕 / 墨蓝 / 樱粉 / 苔绿
- 动态背景随天气变化（晴天粒子、阴天云朵等）

## 使用

直接用浏览器打开 `index.html`，无需安装任何依赖。

如需 AI 分析功能，点击右上角 ⚙️，填入 [DeepSeek API Key](https://platform.deepseek.com)。

**数据备份**
- **导出**：点击顶栏「↓ 导出」，将所有笔记和回忆下载为 JSON 文件（文件名含日期）
- **导入**：点击「↑ 导入」，上传之前导出的 JSON 文件即可恢复数据（会覆盖当前数据，操作前有确认提示）

## 数据说明

所有记录存储在浏览器的 `localStorage`，不上传任何服务器。清除浏览器数据会同时清除笔记，建议使用导出功能定期备份。

## 技术栈

纯 HTML + CSS + JavaScript，零依赖，单文件交付。
